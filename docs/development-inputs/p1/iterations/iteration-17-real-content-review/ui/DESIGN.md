# Iteration 17 — ACF Existing Desktop Shell（冻结）

## 1. AppShell

- 桌面画布 1600 × 1280，应用铺满画面，不绘制浏览器或设备外壳。
- 左侧固定导航 244px，顺序：`首页、项目、素材、作品、流程`；当前全局项为“项目”。
- 顶部全局栏 60px：搜索、帮助、通知、CA 头像、创作管理员。
- 项目头固定：`项目 / acf17-review-001`、`霓港纪事`、`小说`、`策划中`、更新时间。
- 项目 Tab 固定顺序：`概览、策划、素材、故事线、章节规划、审核、作品、设置`。
- 01/02 Frame 在编辑器路由激活“作品”；03–08 Frame 在审核路由激活“审核”。
- 禁止在不同状态重新设计侧栏、顶部栏、项目头或 Tab。

## 2. 视觉系统

- 企业级 SaaS，紧凑、克制、可开发；字体 Inter/Noto Sans CJK。
- 主色 `#5146E5`，工作区 `#F7F9FC`，边框 `#E6EAF0`。
- 卡片白底、1px 边框、6px 圆角；仅抽屉和浮动操作条使用轻阴影。
- 标题 22px/600，区块 15–16px/600，正文 13–14px，元数据 12px。
- 只使用中文业务文案；Run ID、Report ID、Schema 名称和错误码可保留英文。
- Material Symbol 名称不得作为可见文字；图标控件必须有中文 aria-label。

## 3. 审核业务视觉规则

- 审核始终显示“固定版本 Vx”和来源关系。
- queued/running、工作流失败、输出校验失败、结果消费失败必须视觉区分。
- Report/Issue 与 Runtime 技术错误分区，不得把业务问题当成系统故障。
- 失败页只展示脱敏信息；不显示原始 JSON、内部节点、URL、SQL 或堆栈。
- Iteration 17 中所有“创建重写任务”控件必须禁用，并标注 Iteration 18 开放。
- 历史报告和全文定位只读，不允许从审核页直接修改正文。
