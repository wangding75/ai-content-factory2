第08章 雨夜来客

夜雨瓢泼，霓港市的老城区在水雾中显得格外朦胧。街角的霓虹灯招牌闪烁不定，发出滋滋的电流声。李青裹紧了风衣，在一处幽深的巷口停下脚步。

这是一条很少有人涉足的窄巷。空气中弥漫着潮湿的霉味和隐约的铁锈气息。根据线人提供的消息，那个代号"黑鼠"的家伙今晚就会在这里进行交易。

issue_001

突然，一道闪电撕裂夜空，借着那一瞬间的惨白光芒，李青看清了地上的那滩暗红。他不可遏制地尖叫出声，丢下手中的手电筒，转身就跑，连头都不敢回。

雨水很快冲刷掉了巷子里的痕迹。直到第二天清晨，打扫街道的环卫工人才在垃圾桶旁边发现了一把带有血迹的折叠刀。

issue_002

警局的钟声敲响了午夜十二点，太阳正从东方的海平面升起，刺眼的阳光穿过百叶窗，打在李青满是汗水的脸上。他看着桌上的结案报告，久久不能平静。

"这件案子，远没有结束。"他低声喃喃，拿起桌上的咖啡一饮而尽。
