第08章 雨夜来客

雨下得很大，整个霓港仿佛被一层厚重的灰色幕布笼罩。街边的霓虹灯在积水中反射出支离破碎的光斑，红与蓝交织成一种诡异的迷幻色彩。陈克站在窗前，指间的香烟已经燃到了尽头，那一截灰白的烟灰摇摇欲坠，最终还是砸落在了老旧的木质窗台上。

"咚咚咚。"

沉闷的敲门声在寂静的房间里显得格外刺耳。陈克没有立刻转身，他透过玻璃的倒影看着紧闭的房门。这么晚了，会是谁？他知道，自从接下那个委托之后，自己的行踪就已经不再是秘密。他慢慢地将烟蒂碾灭，右手不着痕迹地滑向后腰，冰冷的金属触感让他稍稍感到了一丝安心。

"谁？"陈克的声音沙哑而低沉。门外安静了片刻，随后传来一个女人微弱但清晰的声音："是我。你需要的东西，我带来了。"陈克的瞳孔骤然收缩，是林曼，她居然还活着。他快步走到门边，透过猫眼确认了外面那个浑身湿透的女人，随即迅速打开了门。
