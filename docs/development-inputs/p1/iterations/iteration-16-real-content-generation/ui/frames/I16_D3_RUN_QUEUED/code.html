第一章 迷雾之城

1.1 迷雾降临

夜色如浓稠的墨水般在艾伦达尔城的上空化开，那场预言中的迷雾终于毫无征兆地降临了。起初，只是几缕灰白色的絮状物在鹅卵石铺就的街道上游荡，像是冬日里不安分的寒风带来的幻影。但很快，这雾气便浓烈起来，带着一股淡淡的铁锈与海腥混合的味道，迅速吞没了高耸的钟楼和那些雕刻着神圣符文的飞檐。

艾伦站在旅馆三楼狭窄的窗前，手中紧紧握着那枚已经失去光泽的银色吊坠。玻璃窗外，原本应该灯火通明的集市现在只剩下一片混沌的灰暗。偶尔有微弱的黄色灯光在雾中闪烁，像是在深海中垂死挣扎的鮟鱇鱼。他能听到远处传来的模糊人声，并非平日里的喧嚣，而是夹杂着惊恐与压抑的低语。

“他们说这雾里有东西。”一个低沉的声音从房间的阴影处传来。是老酒馆老板，他正用一块粗糙的麻布擦拭着一柄生锈的火枪，眼神警惕地盯着那扇几乎被雾气糊满的窗户。“以前也有过起雾的时候，但从来没有像这次一样……感觉它在‘呼吸’。”

艾伦没有回头，只是微微皱起了眉头。他知道老头说得没错。这并非普通的自然现象。当他闭上眼睛，甚至能感觉到雾气中某种微弱的魔力波动，如同无数根细小的针在轻轻刺探着他的感知屏障。他的导师曾经警告过他，当迷雾之城的传说成为现实，便意味着某种古老的封印已经开始松动。
