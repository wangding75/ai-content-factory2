# P0 E2E 回归场景

本文件记录 P0/Mock 用户链路的基础回归场景。这些场景必须继续保留，用于确认第二用户闭环开发没有破坏既有能力。

本文件不是 Iteration 15～18 全部真实业务链路的完整验收矩阵，也不代表真实 n8n、真实 LLM 或 Iteration 19 最终验收已经通过。Iteration 15～18 已完成的浏览器 UI 对比验收应单独引用对应报告。

所有涉及数据库的场景只使用唯一数据库 `ai_content_factory`。测试通过事务、唯一项目命名空间或 Run ID 隔离，不创建独立测试数据库，不清空数据库，不执行 Migration Down。

## E2E-01 项目创建

创建项目后进入概览，返回列表和刷新后仍可见。

数据库断言：项目只创建一次，刷新不产生重复记录。

## E2E-02 素材本体与用途

项目 A 创建人物，项目 B 绑定同一人物；编辑 B 用途不影响 A；解除 B 绑定后全局人物仍存在。

数据库断言：素材本体、项目 Usage 和解除关系符合设计，不误删共享素材。

## E2E-03 故事线与伏笔

创建主线、子线和伏笔，刷新后树关系和计划章节保持正确。

数据库断言：父子关系、排序和伏笔关联在刷新后保持一致。

## E2E-04 Mock 章节规划

Mock 生成候选，编辑、删除、确认；确认后不自动创建正文；显式进入生产后创建正文。

该场景只验证 P0 Mock 回归，不可作为真实 n8n 章节规划或真实 LLM 验收证据。

## E2E-05 审核不覆盖正文

保存 v1，执行审核，确认 v1 body 未变化且 ReviewReport 关联 v1。

数据库断言：审核报告与源版本关系正确，审核过程不修改源正文。

## E2E-06 重写保留版本

从 v1 创建 v2，确认 v1 和 v2 均存在、parent 关系正确、current 仍按 P0 规则保持。

数据库断言：旧版本没有被覆盖，父子版本关系和当前版本符合 P0 规则。

## E2E-07 全局聚合

全局素材和作品可查询到来源项目；流程中心显示对应 Mock WorkflowRun；设置页面准确显示能力状态。

设置页面不得把 Mock、确定性 n8n 工作流或未完成的 LLM 链路显示为完整真实 AI 能力。
